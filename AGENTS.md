# Code-First Agent Rules

- For coding requests, inspect the minimum relevant files and implement changes immediately.
- Do not spend time exploring the entire repository or generating lengthy plans.
- Do not run terminal commands for directory discovery, port checks, or process inspection unless necessary.
- Do not repeat searches or commands when existing results are sufficient.
- Focus on `ecommerce_frontend` for frontend tasks and `ecommerce_backend` for backend tasks.
- For integration tasks, inspect only the necessary frontend files and backend API contract.
- Preserve existing architecture, API contracts, and unrelated changes.
- After implementation, run only the smallest relevant validation.
- Report blockers clearly. Never claim unverified tests passed.
